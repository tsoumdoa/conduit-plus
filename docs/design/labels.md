# Labels

**Decision.** Labels are viewport annotations owned by Overlay. They follow its View, document, theme, Preview and Enabled state. They create no Rhino objects and contribute no card slots. The shortest definition is Geometry + Keys → Link → Overlay Links, then check **Show Link keys** on Overlay. Default off, persisted with undo. An Overlay with zero cards is a valid label display.

## Wiring and identity

Append one optional **Labels** tree after the current last Overlay input. Accept a Link directly (default styling) or a Labels specification. Link supplied there also registers its geometry for brushing. Show Link keys synthesizes default specifications for existing Links. Within an owner, an explicit specification for the same Link snapshot supersedes its automatic labels and geometry registers once. Retain all existing GUIDs, input indices and outputs. Use Overlay's trailing-parameter archive read guard and test reopening a pre-label file with wires intact.

New **Labels** component, new stable GUID, one specification output. Inputs in order are **Link, Points, Text, Keys, Short text, Colours, Priority**. Link is an optional single item; other inputs are optional lists per GH branch. Choose either Link or Points; supplying both reports an error on that branch. Link mode uses the Link's declared key order, defaults Text to keys and rejects a Keys override. For each key use its first valid geometry item in original input order. Emit one anchor per distinct geometry-backed member; skip key-only members with a counted Remark. Align overrides against declared keys *before* skipping. Explicit mode requires finite Points and Text; Keys are optional, unkeyed annotations have local hover only. Repeated explicit keys are separate positions for the same member. Broadcast one styling/text value or require exactly the source count; Keys must match Points exactly. Report branch/index on invalid values; larger finite Priority wins, default zero.

Compute anchors once per requested Link snapshot, retaining key-to-source association during Link construction. Use the point itself, curve half arc length, or area centroid projected to the nearest valid trimmed face/mesh triangle (including closed solids, where an interior centroid would disappear). Break equal-distance ties in original face order. Fall back to a valid sampled surface point or curve endpoint on degeneracy; skip with a diagnostic if neither exists. A label instance identity includes owner, source component/path and original member key or explicit point index. Identity drives layout history; only member keys travel through the selection domain.

Rejected: a second preview conduit on Labels makes view binding, capture and cross-owner hit order ambiguous. Baking TextDots ties appearance and lifetime to the Rhino document.

## Visibility before layout

Classify each anchor with a CPU segment query before reserving its rectangle. Clip behind-camera, near/far and off-view candidates first. Unproject its device pixel at the near plane and cast toward the anchor (also correct for parallel projection). Let D be segment length. Count any two-sided triangle hit at 0 ≤ t < D − b, using a unit ray and b equal to a quarter device pixel in world units at anchor depth, floored by coordinate roundoff. Keep the member's own triangles: its front face must hide a back-face anchor on a closed solid. The endpoint allowance admits a coplanar anchor without exempting its whole object. An occluded ordinary label contributes no paint, hit or layout rectangle. Effective hover or selection draws its entire glyph at 45% opacity.

**Rhino sources.** Per target document and viewport include visible objects on effectively visible layers (including parents and viewport overrides). Exclude hidden/deleted objects and locked objects when locked geometry is hidden. Include visible locked faces. Consult effective object/view display attributes: only filled faces block, so a wire-only object leaves its interior clear. Mesh objects supply faces directly. Prefer existing render meshes (analysis meshes for a matching analysis display) for Brep, Extrusion and SubD. On a miss, snapshot the changed shape and tessellate at document render settings once. Cache by document, object runtime serial, event-maintained geometry revision and meshing settings. Split quads consistently, skip invalid/degenerate faces. Use binary coverage for opaque faces; skip known transparent previews. Custom display modes, shader transparency and user clipping planes need explicit adapters for exact parity.

**GH sources.** Enumerate preview-contributing active definitions for the view's Rhino document. Apply document preview enablement, no-preview, shaded/wire and selected-only filters, then owner selection, enabled/unlocked state and IGH_PreviewObject capability/Hidden flags. Standard components contribute preview-enabled output params' solved VolatileData across all branches; floating params contribute their own tree. For built-in Custom Preview match the shipped ComponentGuid pinned from the native proxy in the host fixture, independent of nickname/localisation. Read its solved Geometry input (slot 0) even when upstream preview is hidden. Respect its material and effective face pass. Rhino wireframe suppresses Rhino fills; GH geometry blocks only when its own effective preview draws filled faces in that view. Points and curves never block. Extract supported IGH_GeometricGoo as meshes, trimmed breps/surfaces, extrusions or SubD and triangulate as above. A third-party draw override may render unrelated geometry. Skip known custom drawers without an adapter; allow a type-GUID adapter to supply actual filled geometry or opt out. Unknown overrides using ordinary outputs can misclassify. Link pick meshes alone miss unrelated scene objects.

**Index lifecycle.** Core owns immutable double-precision triangle arrays and per-source AABB BVHs under a top-level bounds BVH. Traverse intersected bounds near-first and exit on the first qualifying hit. Replace only changed source trees; refit/rebuild the top level for changed bounds or membership. Queue Rhino add/delete/replace/transform, attribute/show/hide, layer and mesh-setting changes. At GH SolutionEnd refresh changed producers (conservatively all solved producers when revisions are unavailable). Preview/selection/display changes refresh membership without remeshing; document switches detach subscriptions and invalidate pending work. Coalesce changes by generation. Copy host-owned data in bounded UI slices; workers receive detached geometry safe for worker meshing or plain arrays. Build offline, post an immutable snapshot swap/redraw on the UI thread only if the generation still matches. Never wait for a worker in paint. Camera motion only changes queries.

**Frame budget.** Cache answers by snapshot, view projection, clip range, viewport/DPI and anchor revision. During orbit query active members first, then round-robin the remainder within the time slice. Keep the previous drawn state until revisited, suppress unclassified newcomers, and publish hit regions only for answers verified for this frame's projection and scene. On a scene edit invalidate affected answers; suppress unresolved regions until the replacement snapshot arrives. On settle schedule redraws until every candidate is current. Export requires one complete matching snapshot and classification before composition.

**Headless gates.** Core xUnit compares BVH any-hit against brute force, including parallel rays, triangle edges, planar/grazing anchors, a blocker just inside/outside bias and front/back anchors on one solid. Fake clock tests cover stale builds, fair time slices, retained visibility, hit invalidation and settled convergence. In hidden RhinoCore with a solved headless GH definition, independently insert a Rhino box, standard output mesh, floating mesh param and native Custom Preview with upstream hidden. Assert expected interior/clear anchors, faded selected glyph and matching hit identity. Toggle owner/document preview, selected-only selection, hidden layer and wire-only versus shaded passes; move a blocker with fixed camera. Require zero oracle mismatches after settling. Read production classifications directly; headless GH need not paint pixels.

Replay 600 warm fixed orbit/zoom frames in perspective and parallel at 1×/2× with 500 and 5,000 anchors crossed with 50k and 500k triangles. Record hardware, p50/p95/p99 for harvest/copy, projection/cull, queries, layout, composite and baseline-subtracted total UI time, plus cold/incremental worker build and change-to-publication latency. PR 1 gates cull + classification at p95/p99 ≤2/4 ms (500) and ≤5/8 ms (5,000); integrated total retains those budgets. Count deferred work: each eligible anchor revisited within four orbit frames and fully current within four settled frames of snapshot publication. Fail recurring ≥16 ms UI stalls or any camera-triggered rebuild. Report Windows/macOS headless results separately and record unavailable host coverage explicitly.

Rejected: ZBufferCapture has no depth buffer in hidden RhinoCore (GrayscaleDib throws natively, WorldPointAt accesses invalid memory); sampling inside DrawForeground also crashed. Per-frame full scene meshing makes orbit cost depend on unchanged geometry. Per-letter depth testing supplies neither a whole-label decision nor a CPU hit result.

## Placement and paint

One frame per viewport across participating owners. Project in device pixels, convert once to CSS px (96 per inch) with the view DPI. Reserve HUD/card rectangles first. Within the viewport rank selected, hovered, then ordinary candidates, descending Priority within tier, then stable owner/source identity. Each candidate tries full, short, dot, then suppression if even dots overlap. A 32 px spatial hash indexes accepted bounds. Use local projected spacing (nearest other anchor within 96 px, saturating beyond it): full eligible above 48 px, short above 18 px, otherwise dot. Selected/hovered may always try full. Full width measured up to 160 px; short uses authored Short text or first five grapheme clusters plus ellipsis. Anchor dot is centred, pill begins 4 px beside it. Reserve 2 px clearance, try the opposite side at the viewport edge. Coincident anchors have a deterministic winner.

Keep the last side/form by identity. Demote on a real collision immediately; otherwise cross the density boundary by 4 px before changing. Promote after 120 ms of continuous fit with 4 px spare clearance; schedule one settled redraw. Use exact collision checks after grid lookup. Keep previous side first and use a larger exit region (3 px) around the original dot and expanded pill while pointer hover owns it. Direct dot hover immediately opens its full pill as a transient popover above labels but below HUD, independent of selection rank. Scene projection tracks every frame; hysteresis affects form only.

Use the card painter's font and resolved ink/surface tokens for Auto, Paper, Night, Smoke and Blueprint. Regular 11 CSS px, 16 px line, 4 px horizontal padding, 18 px height, 6 px corner radius, no shadow. Use an almost opaque theme surface behind text, verify 4.5:1 ink contrast over black, white and busy previews before fading. Dot diameter 5 px with a 1 px contrasting surface rim. Default dot is neutral data ink. Authored colour supplies a 4 px swatch or dot, never the text. Selection uses only the theme accent in a 2 px ring; preserve swatch and ink. Hover uses a thin outline. Red/green carry data only when explicitly wired.

## Input, output and capture

OverlayManager hit order is tooltip/overflow/cards, visible label, then model. Draw and pick from the same completed view frame; invalidate hits on camera changes until republished. Dot hit radius 5 CSS px, ties go to nearest centre then paint order. Hidden and suppressed labels have no region. Run through existing paced move, gesture cancellation and macOS input adapter; wheel and navigation pass through. Tooltip shows full text, distinct key and existing containing-group summary, local to pointer. A keyed click targets exactly one member. Plain replaces, Shift adds, Ctrl removes, Ctrl+Shift toggles; on Mac substitute Command for Ctrl, Control-click remains secondary. Unkeyed clicks pass through. Provide **Clear selection** in the Overlay menu for labels-only displays; reuse domain Clear. Escape closes a popover without altering selection.

Register label keys with existing private/shared Scope membership and atomic pruning. Effective member sets drive model wires, bars, rows and labels, including group hover without recursive expansion. Clear hover only for its originating generation. Selection is the sorted unique domain union. Events retain the bounded 32-action history and existing fields, adding label as sourceSurface with stable source identity. Use the existing action dispatcher and coalesced output solve once per accepted action. Hover, camera and LOD never solve.

PNG/PDF commands snapshot the eligible view before conduit suppression. Resolve a clean export frame at logical viewport size using the matching occluder snapshot, retaining selection and omitting hover, tooltip and popover; scale the placements for output, then draw cards above. Test crop/tile offsets and high-resolution PNG against the same logical view. PDF paints pill paths and searchable text over the scene image. Never draw labels in both the scene image and overlay pass. Restore live state on failure. Copy card as image remains card-local. Canvas Card and Canvas Overlay participate through Scope; neither has a 3D projection or draws labels.

## Cost, delivery and checks

Premeasure distinct full/short strings per font/DPI. Cache premultiplied pill rasters using existing platform raster adapters, keyed by resolved text, colours, font, DPI and form. Draw transient rings separately; cap textures at 16 MiB per view with LRU disposal. Batch identical dots. Budget cold uploads per frame; while pending, draw a measured neutral or authored dot and publish its actual hit bounds. Release native resources on detach/close and DPI/theme replacement. Content edits invalidate affected entries; camera changes invalidate classification/projection/layout only. Pre-sort stable priority buckets on data change. Bound nearest-neighbour cost in coincident cells using occupancy and bounded-radius queries; benchmark all-coincident as well as uniform distributions.

During projection changes and for 120 ms after the last change, the foreground pass gives ordinary pills a fixed count per frame in placement rank order. Selected and hovered pills are exempt. A smoothed estimate of warm draw cost targets 1.5 ms and adjusts the count at most every 250 ms when the estimate moves by more than 25%. Paint-time dot fallbacks keep the layout's form and side history, and publish the actual drawn geometry. Motion frames use spare upload slots to prepare up to four deferred pills. A scheduled settled redraw removes the cap and draws every placed pill.

## Owner decisions (2026-11-24)

- Several objects sharing a member key get **one label per member**, on its first valid geometry item in input order.
- A supplied colour shows as a **swatch** in a neutral themed pill; the collapsed dot takes that colour.
- Testing is headless only, through Core tests and hidden RhinoCore with headless Grasshopper. Drop the ZBufferCapture route.
- Both Rhino objects and Grasshopper preview must occlude labels, including geometry unrelated to a Link.

The viewport foreground pass draws labels during live redraws. PNG, PDF and clipboard retain their existing output through PR 3. Label composition for export is scheduled for PR 5.
