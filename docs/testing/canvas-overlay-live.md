# Canvas Overlay live acceptance checks

Implementation slice: shared controller plus widget host, fixed-size first-cut rails, selection/Scope, tooltips and explicit overflow remarks. No live Rhino session was automated, killed, restarted or changed during implementation. These are outstanding owner checks, not verified behavior.

## Metadata probe

Run `pwsh -NoProfile -File tools/Probe-CanvasWidgets.ps1` against the pinned package. Reflection reads Grasshopper 8.20.25147.11001 from `~/.nuget/packages/grasshopper/8.20.25147.11001-rc/lib/net7.0` without loading RhinoCommon for execution.

- Widget types are in `Grasshopper.GUI.Widgets`. `GH_Widget` exposes public abstract rendering, Contains, Visible, Name, Description and Icon_24x24; mouse/key/tooltip/menu methods are overridable. No wheel override exists.
- `Owner` implements the interface as a **final virtual** property; it cannot be overridden. The adapter sets it explicitly and attaches lifecycle hooks separately.
- `GH_Canvas.WidgetListCreated` is public/static; its delegate takes `(object, GH_CanvasWidgetListEventArgs)`. AddWidget is public. `Instances.CanvasCreated` takes a GH_Canvas.
- Contrary to the design's implication of direct availability, `GH_Canvas.Canvases` is **internal static** in this package. Optional discovery uses reflection only inside the adapter, then reconciles ActiveCanvas and future CanvasCreated events. A missing internal discovery property falls back to ActiveCanvas/future canvases; a throwing adapter fails closed and leaves a persistent error.
- Compass derives from FixedObject and exposes ControlLocation/Size. Markov exposes public DockCorner/IconLimit/visibility, but no public painted bounds. This slice yields its hits; its measured safe-area reservation remains PR 3 work. Profiler is not excluded or hidden.

## Owner checks (Rhino 8.20 and installed newer version)

1. **Creation/registration assumption:** WidgetListCreated's sender is the canvas when available; CanvasCreated reconciliation finds the early-added widget, assigns Owner and attaches once. Test a canvas open before plug-in load, canvases created afterward, widget-list recreation and multiple canvases. Each list must contain exactly one Conduit+ widget; other widgets stay intact.
2. **Dispatch assumption:** GH calls widget Contains/mouse handling before component objects and wires, and Ignore permits navigation. Put components and wires directly under cards. Ordinary body clicks must never select/drag underlying objects. Gaps/shadows pass through; right-click opens Find/Hide, middle and Alt gestures navigate, and no HUD gesture starts during wire/drag/modal interactions. Check double-clicks too.
3. **Capture assumption:** ActiveWidget plus control capture routes moves and release to the accepted gesture. Escape/modifier changes cancel; scrollbar drag rolls back. A cancelled gesture relinquishes physical capture but retains GH release ownership until the matching left release; idle timer cleanup removes ownership if release occurs outside the window. Test Escape, lost capture, release outside the window, navigation, hide, resize, data changes, disable and tab switches. No click-through release or idle invisible blocker may remain; capture belonging to another widget/object must never be cleared.
4. **Graphics/DPI assumption:** canvas.DeviceDpi supplies the actual device scale, and resetting/saving/restoring canvas.Graphics with Pixel page units establishes client-device coordinates once. Test 100%, 110%, 125%, 150%, 175% and mixed-monitor moves. Cards and hit regions must align; shadow pixels must not become hits. Continuously pan/zoom: rasterization count must stay flat. Resize may move/hide but must reuse retained raster identities at unchanged DPI. Theme, data or DPI changes should rasterize again. `ConduitPlus.CanvasWidgets.WidgetService.RasterizationCount` is available for the live probe.
5. **Tooltip assumption:** GH supplies a canvas-space PointF to widget tooltip methods, while GH_TooltipDisplayEventArgs.Region is control-space. Verify every card kind, table headers, sort/scroll re-hit, dragging/navigation suppression, below-menu/tooltip layering, and no remote Scope tooltip.
6. **Menu assumption:** GH discovers the single `Conduit+ cards` entry via Name/Visible/AppendToMenu, including when hidden. Test Widgets hide/show, owner recovery when already visible but memory-evicted, and per-canvas session independence; none may solve or change selection.
7. **Export assumption:** GH invokes Render with DrawingMode != Control for tiled definition export. Export must contain no pinned pixels or hits, leave the screen frame intact, and avoid raster generation. An OS screenshot must include the HUD. Existing inline Canvas Card export stays unchanged.
8. **Lifecycle/state:** lock and document disable retain a complete Disabled frame and frozen membership; unlock reprojects current Scope state. Global solver pause allows sort/scroll/selection and resumes pending output. Test preview off/Hidden, tab return without solving, delete/undo while paused, close with queued raster/output work, and repeated close/reopen. No old-document callback, tooltip or bitmap may survive. Check GDI handles and shared raster-byte usage plateau; staging accounts for old/new frames and stops rendering an evicted pinned frame until a meaningful state/layout/recovery change.
9. **Scope/output:** pinned ↔ Canvas Card ↔ Rhino Overlay/model, private displays, multiple/foreign/deleted tokens, grouped keys and Clear, same card in multiple displays, hidden/overflow membership, and Selection feedback wiring. Selection schedules a coalesced output refresh; hover/sort/scroll/theme/show/hide do not. Check paused solver and reconciliation loop guard.
10. **Layout/coexistence:** all six rails, centre titles, multiple owners, narrow/tiny clients, overflow/reinsertion and oversize cards. Compass and scrollbars must not overlap. Profiler remains visible alongside cards. Test Markov corners/icon counts and unknown third-party widgets: this slice yields their Contains hits, but full measured painted reservations and inward wrapping/chip/collapse remain deferred to PR 3.

Record host versions and each outcome before accepting the adapter for release.
